> 🚀 Your AI-powered travel companion with 3D avatar, interactive maps, chat history, and full booking capabilities

## ✨ Features

### 🤖 AI Travel Assistant
- 3D interactive avatar with animations
- Voice recognition support
- Natural language processing
- Chat history with sidebar
- 24/7 automated assistance

### ✈️ Travel Services
- **Destination Research** - Detailed info about cities worldwide
- **Custom Itineraries** - Personalized day-by-day trip planning
- **Visa Assistance** - Requirements and application support
- **Safari Bookings** - African safari packages with Trawell Safaris
- **Travel Tips** - Weather, currency, language, and more

### 🗺️ Interactive Map
- Real-time destination mapping with Leaflet
- Clickable location markers with detailed info
- Dynamic map centering on selected destinations

### 👤 User Features
- Firebase Authentication (Login/Register)
- User Profile with stats
- Saved trips and bookings
- Travel checklist
- Dark/Light mode toggle

### 💎 Pricing Plans
- **Standard** (Free) - Basic travel assistance
- **Premium** ($19/mo) - Enhanced features and bookings
- **Luxury** ($49/mo) - VIP treatment and unlimited access

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn
- Firebase account

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/wanderly-travel.git

# Navigate to project directory
cd wanderly-travel

# Install dependencies
npm install

# Create .env file with your Firebase config
# Get from Firebase Console → Project Settings → Your apps → Config

# Start development server
npm run dev
